# liquid-glass-toolbox

简单的液态玻璃组件示例仓库。

本仓库包含一个最小化的测试页面 `index.html`，用于演示“液态玻璃按钮”（使用 backdrop-filter 与 SVG goo 滤镜）。

如何运行：

1. 克隆仓库：
   git clone https://github.com/OMG17639303359/liquid-glass-toolbox.git
2. 进入目录并直接在浏览器中打开 `index.html`（无需构建工具）：
   cd liquid-glass-toolbox
   open index.html # 或直接在文件管理器中双击打开

说明：部分浏览器或系统可能不支持 `backdrop-filter` 或 SVG 滤镜，建议使用 Chrome/Edge/Safari 的较新版进行测试。
